## Technical Details

### Architecture Highlights

1. **Brand-Agnostic Core**
   - All conversion logic lives in `/packages/core`
   - Zero dependencies on brand-specific UI or terminology
   - Reusable by CLI, extension, and web interface

2. **Separation of Concerns**
   - Parsers handle input validation and parsing
   - Generators produce output in target formats
   - Utilities provide pure functions for color manipulation
   - Types provide single source of truth for data structures

3. **Quality & Validation**
   - Zod schemas ensure data integrity at boundaries
   - Comprehensive type safety with TypeScript strict mode
   - Full test coverage for critical paths
   - Error handling throughout the pipeline

### Type Safety

All code written with TypeScript strict mode enabled:
- No implicit `any` types
- Full type coverage for public APIs
- Comprehensive JSDoc comments
- Zod validation schemas for external data

### Testing Strategy

- **Unit Tests** - Individual function behavior
- **Integration Tests** - Full conversion pipeline
- **Edge Cases** - Malformed input, missing properties, type variations
- **Example Data** - Real theme snippets from Dracula, Nord, etc.
