# @chromamancer/vscode-extension

VS Code extension with brand-specific UI

## Overview

Visual Studio Code extension for transmuting themes between VS Code and Obsidian formats.

## Features

- Theme conversion within VS Code
- Preview before conversion
- Batch conversion support
